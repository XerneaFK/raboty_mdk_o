Вариант 8. Ресторан — инструкция по запуску

1. Установите Python 3.10 или новее.
2. Распакуйте архив в отдельную папку.
3. Откройте терминал (командную строку) в папке restaurant_variant8.
4. Создайте виртуальное окружение:
   python -m venv venv

5. Активируйте его.

   Windows:
   venv\Scripts\activate

   macOS / Linux:
   source venv/bin/activate

6. Установите Django:
   pip install -r requirements.txt

7. Создайте таблицы базы данных:
   python manage.py makemigrations restaurant
   python manage.py migrate

8. Создайте администратора (необязательно, но удобно):
   python manage.py createsuperuser

9. Запустите сайт:
   python manage.py runserver

10. Откройте в браузере:
    Главная: http://127.0.0.1:8000/
    Меню: http://127.0.0.1:8000/menu/
    Создание заказа: http://127.0.0.1:8000/orders/create/
    Админка: http://127.0.0.1:8000/admin/

Перед тестированием добавьте через админку категории, блюда и столики.
Для заказа нужно, чтобы в базе уже были хотя бы одно блюдо и один свободный столик.

Как проверить фильтр:
Откройте /menu/, выберите категорию и нажмите «Фильтровать».
Можно также открыть адрес /menu/?category=1 (если категория с ID 1 существует).

Примечание:
Это учебный локальный проект. SECRET_KEY оставлен учебным, DEBUG включён.
Не используйте такие настройки на реальном сайте.
